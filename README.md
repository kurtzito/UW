# URW Panel

A clickable side panel for playing **UnReal World** with the mouse, written in AutoHotkey v2.

The panel sits in one of the black bars beside the game (UnReal World is drawn in 4:3). Each button sends the real key to the game without taking focus away from it.

## Features

- Buttons for menus, survival, combat, movement and more, grouped by color.
- Holding a button down repeats the key (arrows, zoom, waiting…).
- Save and Quit ask for confirmation first.
- Middle click = Esc while the game is active.
- 🔓 **Edit mode**: rearrange the buttons.
- 🎨 **Color mode**: repaint any button with a color from a palette.
- 5 languages: Español, English, Suomi, Português, Italiano.
- Hide it to a small tab at the screen edge, or move it to the other side.
- Your side, language, layout and colors are saved automatically.

## Quick start

1. Install [AutoHotkey v2](https://www.autohotkey.com).
2. Download `urw-panel.ahk`.
3. Open UnReal World, then double-click `urw-panel.ahk`.

The panel starts in Spanish: click the 🌐 button to change the language.
