=====================================================================
  БОКОВАЯ ПАНЕЛЬ ДЛЯ МЫШИ К UNREAL WORLD  (urw-panel.ahk)
=====================================================================

Панель с кнопками, которая занимает одну из чёрных полос по бокам
игры (UnReal World рисуется в формате 4:3). Каждая кнопка отправляет
в игру настоящую клавишу, не забирая у игры фокус, так что почти всё
можно делать мышью.


---------------------------------------------------------------------
 УСТАНОВКА И ЗАПУСК
---------------------------------------------------------------------

1. Установите AutoHotkey v2 (https://www.autohotkey.com).
2. Запустите UnReal World.
3. Дважды щёлкните по файлу urw-panel.ahk.

Панель появится справа. Чтобы закрыть её: кнопка «Закрыть» или правый
щелчок по зелёному значку «H» в области уведомлений → Exit.

Панель запускается на испанском языке: нажимайте кнопку 🌐, пока не
появится «Русский». Выбор запоминается.


---------------------------------------------------------------------
 УСТРОЙСТВО ПАНЕЛИ
---------------------------------------------------------------------

Наверху расположены кнопки самой панели (они не отправляют клавиши в
игру, кроме «Справка», «Сохранить» и «Выйти»):

   [ 🔒 Блок.  ]  [ ⇄ Сторона ]  [ 🌐 Русский ]
   [ Скрыть    ]  [ Закрыть   ]  [ Справка    ]
   [ Сохранить ]  [ Выйти     ]  [ Сброс      ]

Под ними находится строка состояния: она показывает последнюю
отправленную клавишу (например «Инвентарь → i») или подсказывает, что
делать в текущем режиме.

Дальше идут игровые кнопки: от редко используемых (сверху) к самым
частым (снизу). У каждой группы свой цвет:

   Салатовый ...... меню (инвентарь, навыки, ремесло…)
   Голубой ........ информация (броня, профиль, карта, F1…)
   Серый .......... выживание (есть, пить, огонь, спать…)
   Жёлтый ......... ждать, осмотреть, зум
   Красный ........ бой и охота
   Коричневый ..... действия (подобрать, выложить, открыть, бежать…)
   Оранжевый ...... отдельные клавиши (4, 5, 6, 8, Tab, PgUp, PgDn)
   Синий .......... движение и повороты
   Малиновый ...... Пробел и Enter
   Белый .......... Esc

В самом низу — крупные кнопки Пробел, Enter и Esc.


---------------------------------------------------------------------
 ИСПОЛЬЗОВАНИЕ
---------------------------------------------------------------------

- Щелчок по кнопке = нажатие этой клавиши в игре.
- Если удерживать кнопку, клавиша повторяется. Это работает для
  стрелок, шагов вбок, «Ждать 1», зума и + / −.
- «Сохранить» (Ctrl+S) и «Выйти» (Shift+Q) перед отправкой клавиши
  спрашивают подтверждение.
- Средняя кнопка мыши (колёсико) = Esc, но только когда активно окно
  игры.


---------------------------------------------------------------------
 ЗАМОК: ПЕРЕСТАНОВКА И ОКРАСКА КНОПОК
---------------------------------------------------------------------

Каждый щелчок по замку переключает режим:

   🔒 Блок.  →  🔓 Правка  →  🎨 Цвета  →  🔒 Блок.

Пока замок не закрыт, кнопки НЕ отправляют клавиши в игру.

🔓 ПРАВКА (переставить кнопки)
   Фон панели становится тёмно-красным.
   1. Щёлкните по кнопке: она подсветится зелёным.
   2. Щёлкните по другой кнопке (или по пустой клетке «·»): они
      поменяются местами.
   Широкие кнопки (Пробел, Esc) тоже можно переставлять; если они не
   помещаются в выбранное место, появится «Сюда не помещается».
   «Сброс» возвращает исходный порядок.

🎨 ЦВЕТА (покрасить кнопки)
   Фон панели становится тёмно-синим, а под строкой состояния
   появляется палитра.
   1. Щёлкните по цвету в палитре: он отметится знаком ✓.
   2. Щёлкайте по кнопкам, которые хотите покрасить. Можно покрасить
      несколько подряд одним цветом.
   - Квадратик ↺ возвращает кнопке её исходный цвет.
   - Цвет текста (чёрный или белый) подбирается сам по фону.
   - «Сброс» в этом режиме возвращает ВСЕ исходные цвета.
   Покрасить можно все игровые кнопки, а также «Справка», «Сохранить»
   и «Выйти». Кнопки управления панелью (замок, Сторона, язык,
   Скрыть, Закрыть, Сброс) не красятся: щелчок по ним выполняет их
   действие.

Перестановка и цвета сохраняются автоматически.


---------------------------------------------------------------------
 ДРУГИЕ КНОПКИ ПАНЕЛИ
---------------------------------------------------------------------

⇄ Сторона .... переносит панель на другую сторону экрана.
🌐 Язык ....... переключает испанский, английский, финский,
               португальский, итальянский и русский. (Меню в области
               уведомлений остаётся на языке, с которым был запущен
               скрипт.)
Скрыть ....... прячет панель и оставляет у края экрана язычок «☰»;
               щелчок по нему снова показывает панель.
Закрыть ...... закрывает панель (не игру).


---------------------------------------------------------------------
 СОЧЕТАНИЯ КЛАВИШ
---------------------------------------------------------------------

   Ctrl+Alt+P ............ показать / скрыть панель
   Ctrl+Alt+L ............ сменить сторону
   Двойной щелчок по значку в области уведомлений = показать / скрыть


---------------------------------------------------------------------
 ГДЕ СОХРАНЯЮТСЯ НАСТРОЙКИ
---------------------------------------------------------------------

В файле urw-panel.ini, в той же папке, что и скрипт:

   [panel]   сторона и язык
   [layout]  порядок кнопок
   [colors]  цвет каждой кнопки

Если удалить этот файл (при закрытой панели), всё вернётся к
исходному виду.


---------------------------------------------------------------------
 РАСШИРЕННЫЕ НАСТРОЙКИ
---------------------------------------------------------------------

В начале файла urw-panel.ahk есть значения, которые можно изменить в
Блокноте (после этого запустите скрипт заново):

   PANEL_W ....... ширина панели в пикселях; 0 = вычислить автоматически
   GAME_RATIO .... пропорции изображения игры (4/3)
   OPACITY ....... прозрачность панели; 255 = непрозрачная
   USE_EMOJI ..... false, если замок, глобус или палитра не видны
   SEND_MODE ..... способ отправки клавиш: "Event", "Input" или "Play"
   KEY_DELAY / KEY_PRESS ....... время каждого нажатия (мс)
   REPEAT_FIRST / REPEAT_EVERY . время повтора (мс)
   TARGET_WIN .... окно, в которое отправлять клавиши (необязательно)
   MBUTTON_ESC ... true / false: средняя кнопка мыши = Esc
   GAME_WIN ...... программа игры, для средней кнопки мыши

Чуть ниже, рядом с цветами групп:

   PALETTE ....... цвета палитры режима 🎨 в формате hex
                   (например "C0392B"). Их можно менять и добавлять.
   PAL_ROWS ...... количество строк палитры
   PAL_H ......... высота строки палитры (1.0 = одна кнопка)


---------------------------------------------------------------------
 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
---------------------------------------------------------------------

- Игра не реагирует на кнопки: попробуйте SEND_MODE := "Input" или
  "Play".
- Средняя кнопка мыши не отправляет Esc: проверьте, что GAME_WIN
  совпадает с программой игры (или оставьте пустым "", чтобы работало
  во всех окнах).
- Вместо замка, глобуса или палитры видны квадратики: поставьте
  USE_EMOJI := false.
- Панель закрывает часть игры или слишком узкая: настройте PANEL_W.
- После перестановки или окраски что-то выглядит странно: нажмите
  «Сброс» в соответствующем режиме.
